## Getting Started

A guide for getting started with Sinar Project

### 1. Repository access on Sinar Project GitHub
- If you don't have permission to contribute back to repositories in [the Sinar Project Github Organisation](https://github.com/Sinar), contact the maintainer team.
- All projects should have an up to date`README.md` based on [the README Template](https://github.com/Sinar/template/blob/main/README.md) to describe the project. 
- Alternatively, new repos can be created with the [Sinar/template](https://github.com/Sinar/template/) repository to facilitate faster updates with README details & instructions.

### 2. Review the Code of Conduct, Contribution & License guidelines for Open Source projects under Sinar
- [CODE_OF_CONDUCT.md](https://github.com/Sinar/kopitiam/blob/main/CODE_OF_CONDUCT.md)
- [CONTRIBUTING.md](https://github.com/Sinar/.github/blob/main/.github/CONTRIBUTING.md)
- LICENSE - For Code reposittories, [AGPL-3.0](https://github.com/Sinar/go-electdocs/blob/main/LICENSE) is preferred, whereas for Content repositories, [CC-BY-SA-4.0](https://github.com/Sinar/template/blob/main/LICENSE) is preferred. 

### 3. Review existing repositories below & join the Community on Mattermost
- Get the [signup link for Sinar Project Kopitiam's Mattermost platform from the website's - Get Involved page](https://sinarproject.org/get-involved) 
- Mattermost is also known as [Sinar Project Kopitiam](https://kopitiam.sinarproject.org/) and the default channel is ~kopitiam. Discussions related to codes are in ~dev-talk channel
